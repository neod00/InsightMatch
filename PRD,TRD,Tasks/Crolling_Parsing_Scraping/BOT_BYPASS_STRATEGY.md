# 쇼핑몰 봇 차단 우회 전략 리포트 (Bot Bypass Strategy Report)

본 문서는 'AI 상세페이지 생성기' 개발 과정에서 쇼핑몰(쿠팡, 11번가 등)의 강력한 오토봇 차단 시스템을 우회하기 위해 적용된 다층적 기술 전략을 정리한 것입니다.

---

## 🛡️ 개요 (Executive Summary)

쇼핑몰들은 비인가 크롤링을 막기 위해 HTTP 헤더 검증부더 고급 브라우저 핑거프린팅 감지까지 다양한 방어 기제를 사용합니다. 본 프로젝트는 이를 우회하기 위해 **7단계 레이어드 방어 체계**를 구축하였습니다.

---

## 🛠️ 7단계 우회 전략 (Layered Defense Architecture)

### 1단계: 기본 스텔스 모드 (Base Stealth)
- **Playwright Stealth**: `playwright-stealth` 라이브러리를 통해 브라우저의 `navigator.webdriver` 속성을 `undefined`로 노출시키고, 기본 헤드리스 속성들을 숨깁니다.
- **User-Agent 랜덤화**: Windows, macOS, Linux 등 다양한 환경의 최신 브라우저 User-Agent를 요청마다 랜덤하게 선택하여 사용합니다.

### 2단계: 고급 핑거프린팅 스푸핑 (Advanced Fingerprint Spoofing - 쿠팡 특화)
- **하드웨어 정보 랜덤화**: CPU 코어 수(`hardwareConcurrency`)와 메모리 용량(`deviceMemory`)을 랜덤하게 설정하여 매번 다른 물리 기기에서 접속하는 것처럼 위장합니다.
- **플러그인 및 폰트 위장**: Chrome PDF Viewer 등 실제 브라우저가 기본적으로 가지고 있는 플러그인 목록을 삽입하고 언어 설정(`ko-KR`)을 강제합니다.
- **Chrome 객체 주입**: 헤드리스 브라우저에는 없는 `window.chrome` 객체를 JavaScript 주입을 통해 생성하여 감지를 우회합니다.

### 3단계: 행동 패턴 시뮬레이션 (Behavioral Simulation)
- **휴먼-라이크 타이핑**: 검색어 입력 시 글자마다 50ms~150ms 사이의 랜덤한 지연 시간을 두어 사람이 직접 입력하는 것처럼 동작합니다.
- **자연스러운 스크롤**: 일정한 속도의 스크롤 대신 '점진적 스크롤', 'Page Down 키 입력', '불규칙한 위치 점프' 등 3가지 패턴을 랜덤하게 섞어 사용합니다.
- **동적 대기 시간**: 페이지 로드 후 3~5초 사이의 랜덤한 시간을 대기하여 봇 특유의 즉각적인 행동을 지양합니다.

### 4단계: 트래픽 유입 경로 위장 (Traffic Origin Spoofing)
- **검색엔진 경유 접근**: 쿠팡 등 차단이 강한 사이트는 직접 URL로 접속하지 않고 **구글, 네이버, 빙** 등 검색엔진에서 키워드 검색 후 클릭하여 유입되는 흐름(Organic Traffic)을 시뮬레이션합니다.
- **도메인 워밍업**: 타겟 페이지 방문 전 해당 쇼핑몰의 메인 도메인을 먼저 방문하여 세션 쿠키와 Referrer 정보를 활성화합니다.

### 5단계: 실행 환경 은닉 (Fake Headless Mode)
- **헤드리스 감지 원천 차단**: 쿠팡의 경우 `headless=True` 옵션을 쓰지 않고 실제 브라우저 창을 띄우는 `headless=False` 모드로 실행합니다.
- **오프스크린 트릭**: 실제 창을 띄우되 브라우저 위치를 화면 밖(`-2400, -2400`)으로 배치하여 서버 환경이나 사용자 PC에서 방해받지 않으면서 감지를 완벽히 우회합니다.

### 6단계: 데이터 추출 전략 (Robust Data Extraction)
- **XHR Response 인터셉션**: DOM 구조가 복잡하거나 자주 바뀌는 경우, 브라우저가 백그라운드에서 주고받는 API 응답(JSON)을 직접 가로채어 정확한 상품명과 가격 데이터를 확보합니다.
- **다중 셀렉터 폴백**: 사이트 개편에 대비하여 각 항목(제목, 가격, 이미지)마다 3~5개의 서로 다른 CSS 셀렉터를 순차적으로 시도합니다.

### 7단계: 리소스 획득 안정화 (Resource Acquisition)
- **이미지 403 에러 우회**: 단순 HTTP 봇의 이미지 다운로드를 차단하는 경우, Playwright 브라우저 인스턴스를 유지한 채 직접 페이지에서 이미지를 렌더링 후 바이너리를 추출합니다.
- **Magic Number 검증**: 다운로드된 파일이 HTML 에러 페이지인지 실제 이미지인지 파일 헤더(Magic Number: `\xff\xd8`, `\x89PNG` 등)를 통해 유효성을 최종 검증합니다.

## 📊 사이트별 맞춤 정밀 전략

| 사이트 | 차단 난이도 | 주요 적용 전략 |
| :--- | :---: | :--- |
| **쿠팡 (Coupang)** | **최상** | Fake Headless, 검색엔진 경유, 하드웨어 스푸핑, XHR 인터셉션, 카테고리 우회(홈페이지 추출) |
| **11번가 (11st)** | **중** | Playwright Stealth, Referrer 위장, 상세페이지 iframe 대응 |
| **G마켓/옥션** | **중하** | User-Agent 랜덤화, 기본 스텔스 모드 |

## 📝 결론

현재 적용된 로직은 단순히 데이터를 긁어오는 수준을 넘어, **쇼핑몰의 보안 엔진이 감지할 수 없는 '실제 사용자'의 브라우징 환경을 완벽히 재현**하도록 설계되었습니다. 이를 통해 반복적이고 대량의 소싱 작업에서도 차단 없이 안정적인 운영이 가능합니다.
