## 2. 현재 프로세스 흐름 (AS-IS)

```
┌──────────────────────────────────────────────────────────────────┐
│                        사용자 입력 (Intake Form)                  │
│  Step 1: 기본 정보 (회사명, 업종, 규모, 지역)                     │
│  Step 2: 관심 인증 (24개 중 복수 선택)                            │
│  Step 3: 경영 현황 (이슈 체크, 인증 배경)                         │
│  Step 4: 추가 정보 (일정, 예산, 비고)                             │
└───────────────────────────┬──────────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────────┐
│                       POST /api/match                             │
│  matching_service.match_consultants(criteria)                     │
│                                                                   │
│  가중치 기반 점수 계산:                                           │
│  ├── ISO Match (30%)                                              │
│  ├── Industry Match (20%)                                         │
│  ├── Project Type Match (15%)                                     │
│  ├── Trust Score (20%)                                            │
│  ├── Region Match (5%)                                            │
│  ├── Timeline/Availability (5%)                                   │
│  └── Reviews/Rating (5%)                                          │
└───────────────────────────┬──────────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────────┐
│                       매칭 결과 화면                              │
│  - 추천 컨설턴트 리스트 (상위 20명)                               │
│  - 각 컨설턴트별 매칭 점수, 매칭 사유                             │
│  - 프로필 보기, 견적 요청 버튼                                    │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 제안 프로세스 흐름 (TO-BE) - 검증 후 적용

> ⚠️ 아래 설계는 **A/B 테스트 후 적용 예정**

```
┌──────────────────────────────────────────────────────────────────┐
│                        사용자 입력 (Intake Form)                  │
│  (기존과 동일)                                                    │
└───────────────────────────┬──────────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────────┐
│              🆕 risk_analysis_service.py (추론 엔진)              │
│                                                                   │
│  1. 입력된 `업종`을 ontology.md의 Knowledge Base와 매칭           │
│  2. `규모`가 "50인 이상"이면 안전/환경 가중치 +20%                │
│  3. `관심 키워드`가 있으면 해당 ISO 우선순위 격상                 │
│  4. 각 ISO 규격별 적합도 점수(0~100) 계산                         │
│                                                                   │
│  출력: RiskAnalysisResult                                         │
│  └── topRisks: ["원청사 평가 대응", "중대재해 리스크"]            │
│  └── recommendedISOs: [{code, reason, matchScore}]                │
└───────────────────────────┬──────────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────────┐
│                  matching_service.py (강화 버전)                  │
│                                                                   │
│  기존 가중치 + ontology 기반 가중치 결합                          │
│  └── 업종-ISO 적합도 추가 점수                                    │
│  └── 이슈 기반 컨설턴트 경험 매칭                                 │
└───────────────────────────┬──────────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────────┐
│                       매칭 결과 화면 (개선)                       │
│                                                                   │
│  ⭐ [주인공] 추천 컨설턴트 리스트                                 │
│     - 컨설턴트 카드 (프로필, 점수, 매칭 사유)                     │
│                                                                   │
│  📊 [조연] 귀사 맞춤 분석 (Accordion - 기본 접힘)                 │
│     "▼ 분석 결과 보기"                                           │
│     └── [펼치면] 업종별 주요 리스크 + 이 컨설턴트가 적합한 이유   │
│                                                                   │
│  💬 문구:                                                         │
│     "AI 엔진이 [업종] 분야의 핵심 리스크 요인을 식별했습니다."    │
│     "귀사와 유사한 환경에서 자주 발생하는 이슈를 매칭했습니다."   │
└──────────────────────────────────────────────────────────────────┘
```

## 4. 데이터 구조 (Interface)

### 4.1 RiskAnalysisResult (Python)

```python
from dataclasses import dataclass
from typing import List

@dataclass
class RecommendedISO:
    code: str           # "ISO 9001"
    reason: str         # "품질 클레임 방지를 위해 필수입니다."
    match_score: int    # 95 (0~100)

@dataclass
class RiskAnalysisResult:
    industry_info: str              # "자동차 부품 제조업"
    top_risks: List[str]            # ["원청사 평가 대응", "중대재해 리스크"]
    recommended_isos: List[RecommendedISO]
    analysis_summary: str           # 분석 요약 문구
```

### 4.2 JavaScript Response

```typescript
interface RiskAnalysisResult {
  industryInfo: string;       // "자동차 부품 제조업"
  topRisks: string[];         // ["원청사 평가 대응", "중대재해 리스크"]
  recommendedISOs: {
    code: string;             // "ISO 9001"
    reason: string;           // "품질 클레임 방지를 위해 필수입니다."
    matchScore: number;       // 95
  }[];
  analysisSummary: string;    // "AI 엔진이 [업종] 분야의 핵심 리스크..."
}
```
